# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1. In short: be respectful, assume good faith, and keep
disagreements focused on the technical or research substance (e.g. a
disputed variable mapping or a validation benchmark) rather than the person
raising it.

Reports of unacceptable behavior can be raised via a repository issue marked
private/sensitive, or directly with the maintainers listed in the repository.
